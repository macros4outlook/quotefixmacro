# Experimental Features

## QuoteColorizer

The colored mode is described in [Advanced Features](https://macros4outlook.github.io/quotefixmacro/advanced-features.html#colored-quotes).
It does not need `mapirtf.dll` anymore.

## Advanced rewrapping

[par](http://www.nicemice.net/par/) was considered for rewrapping the quotes and turned down, see the [decision on wrapping](https://macros4outlook.github.io/quotefixmacro/decisions/0001-wrap-quoted-text-with-built-in-code-instead-of-par.html).
The experimental module `QuoteFixWithPar.bas` has been removed.
